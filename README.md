##  Ключевые команды Git (Шпаргалка)

### 1. Настройка и инициализация
```bash
# Глобальная конфигурация пользователя
git config --global user.name "Ваш Ник"
git config --global user.email "ваша_почта@example.com"

# Инициализация нового репозитория с главной веткой main
git init -b main
```

### 2. Управление изменениями
```bash
# Проверка текущего статуса файлов
git status

# Добавление всех файлов в индекс для коммита
git add .

# Фиксация изменений с комментарием
git commit -m "Commit message"
```

### 3. Работа со структурой и историей
```bash
# Просмотр истории коммитов в компактном виде
git log --oneline

# Просмотр изменений конкретного коммита
git show [хеш_коммита]
```

### 4. Ветки (Branching)
```bash
# Просмотр всех веток (локальных и удаленных)
git branch -a

# Создание новой ветки и автоматический переход на неё
git switch -c feature-branch

# Переключение на существующую ветку
git switch main

# Безопасное удаление локальной ветки после её слияния
git branch -d branch-name
```

### 5. Синхронизация с удаленным сервером
```bash
# Привязка локального репозитория к удаленному
git remote add origin [URL_репозитория]

# Первая отправка изменений ветки main на сервер
git push -u origin main

# Скачивание актуальных изменений с сервера
git pull

# Очистка локальных ссылок на удаленные ветки, которых уже нет на сервере
git fetch --prune
```

##  Сборка и запуск .NET проекта

Для успешного запуска консольного приложения убедитесь, что вы находитесь в корневой директории проекта (где расположен файл `.csproj`), либо указывайте явный путь к нему.

**Запуск из папки проекта:**
```bash
cd backend/Program
dotnet run
```

**Запуск из корня репозитория (без смены папки):**
```bash
dotnet run --project backend/Program
```
